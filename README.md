# Attendance System

Spring Boot backend for automated attendance logging using face recognition and text-to-speech (TTS) notifications.

## Overview
This system automates employee/student attendance by combining computer vision (face recognition) with real-time notifications. It reduces manual check-in friction and provides reliable attendance records.

## Key Features
- Automated attendance capture via face recognition
- Text-to-speech notifications for successful check-ins
- Backend API for logging and retrieving attendance data
- Designed for integration with frontend or mobile clients

## Tech Stack
- **Language:** Java
- **Framework:** Spring Boot
- **Core capabilities:** Face recognition integration, TTS notifications, REST APIs

## Getting Started
1. Clone the repository
2. Configure application properties (database, recognition service endpoints if applicable)
3. Build and run:
   ```bash
   ./mvnw spring-boot:run
   ```
